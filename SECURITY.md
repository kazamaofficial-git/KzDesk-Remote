# KzDesk Remote Security Policy

## Supported versions

Security fixes are prioritized for the latest tagged release and the current `main` branch. Older releases may no longer receive fixes; upgrade before reporting a newly discovered issue when possible.

## Reporting a vulnerability

Use [GitHub Private Vulnerability Reporting](https://github.com/kazamadev/KzDesk-Remote/security/advisories/new). Do not publish exploitable details in a public issue, pull request, discussion, or social post.

Include the affected release or commit, Android version/device, Windows host version where relevant, a minimal reproduction, and the security impact. Remove passwords, tokens, public IPs, certificate private material, and unrelated personal data from logs or screenshots.

Test only systems you own or are explicitly authorized to assess. For a vulnerability in unmodified upstream FreeRDP code, also follow the [FreeRDP security policy](https://github.com/FreeRDP/FreeRDP/blob/master/SECURITY.md); KzDesk Remote reports should still describe any product-specific impact here.

## Response

We will review reports and provide status updates as capacity allows. There is no guaranteed response or remediation SLA. Coordinate disclosure timing with the maintainers; do not assume a report is fixed until a release note or security advisory confirms it.

# Kebijakan Keamanan KzDesk Remote

## Versi yang didukung

Perbaikan keamanan diprioritaskan untuk rilis bertag terbaru dan branch `main`. Rilis lama mungkin tidak lagi menerima perbaikan; bila memungkinkan, perbarui aplikasi sebelum melaporkan masalah baru.

## Melaporkan kerentanan

Gunakan [Pelaporan Kerentanan Privat GitHub](https://github.com/kazamadev/KzDesk-Remote/security/advisories/new). Jangan menerbitkan detail yang dapat dieksploitasi melalui issue, pull request, diskusi, atau media sosial publik.

Sertakan rilis atau commit terdampak, versi/perangkat Android, versi Windows host bila relevan, reproduksi minimal, dan dampak keamanan. Hapus password, token, IP publik, materi privat sertifikat, serta data pribadi yang tidak relevan dari log atau tangkapan layar.

Uji hanya sistem milik sendiri atau yang penggunaannya telah diizinkan secara eksplisit. Untuk kerentanan pada kode upstream FreeRDP yang tidak dimodifikasi, ikuti juga [kebijakan keamanan FreeRDP](https://github.com/FreeRDP/FreeRDP/blob/master/SECURITY.md); laporan KzDesk Remote tetap perlu menjelaskan dampak spesifik produk.

## Tindak lanjut

Laporan akan ditinjau dan status akan disampaikan sesuai kapasitas. Tidak ada SLA respons atau perbaikan yang dijamin. Koordinasikan waktu pengungkapan dengan maintainer; jangan menganggap masalah sudah diperbaiki sebelum rilis atau advisory mengonfirmasikannya.
